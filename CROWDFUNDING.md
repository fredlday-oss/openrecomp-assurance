# OpenRecomp MIPS32 crowdfunding campaign

The OpenRecomp MIPS32 hardening campaign is live on Crowdfunder:

https://www.crowdfunder.co.uk/p/openrecomp-mips32

This repository provides architecture-neutral assurance infrastructure and already contains bounded MIPS32 assurance evidence. Those results remain explicitly fixture-bounded and do **not** establish general MIPS32 equivalence or arbitrary MIPS32 compatibility.

The campaign funds hardening of the wider OpenRecomp **MIPS32 CANDIDATE** path: ingestion/extraction, semantics and translation, bounded indirect control flow, native/WebAssembly parity and repeatability, rights-safe fixtures, and public documentation/evidence.

**Funding does not make MIPS32 PROVEN. Evidence does.** Existing work is not being rebilled as new campaign work, and any future classification must remain bounded to the evidence actually produced.

The public campaign target is £10,500. The underlying engineering programme is £10,000 net, with the public target accounting for platform transaction fees.

Preserve. Understand. Recompile. Keep software running.
