Goal
Implement the smallest credible v0.1 RV32I assurance reference path using a REAL OpenRecomp lift/translation path while keeping translation semantics outside this repository.

Required workflow
1. Verify git status, current branch, remote and base commit.
2. Locate or clone the public OpenRecomp feasibility repository required for the real RV32I path. Record its exact commit SHA. Do not modify that repository unless a clearly isolated adapter change is unavoidable; prefer consuming versioned outputs.
3. Use rights-safe synthetic/open RV32I fixtures only.
4. Build two intentionally different RV32I ELF artifacts with equivalent expected observable behaviour.
5. Run each through the real OpenRecomp lift/translation path.
6. Capture source ELF, generated IR/C, host executable, metadata, toolchain and OpenRecomp commit hashes.
7. Normalize observations into this repository's versioned schemas.
8. Prove baseline A/B observable agreement.
9. Replay both baselines and prove replay stability.
10. Repeat a clean baseline build/run to measure repeatability without overstating byte-for-byte identity where toolchain metadata differs.
11. Implement five distinct semantic divergence seeds covering the classes in the workplan.
12. Diagnose the previous bounded 3/5 result and improve principled detection to 5/5. No seed-name checks, hard-coded expected hashes, or mutation-specific bypasses are allowed.
13. Run a clean baseline after seeded tests to prove no state contamination.
14. Make the bounded suite runnable through CI or document the exact blocker if hosted CI cannot provide the required toolchain.

Verdict rules
- Emit V0_1_GO only if every mandatory acceptance item in the workplan passes, including 5/5 divergence detection.
- Otherwise emit V0_1_NO_GO.
- Preserve failed evidence. Never convert an incomplete test into PASS.
- Keep PROVEN, BOUNDED, CANDIDATE and FAILED claims distinct.
- V0_1_GO is a bounded RV32I assurance result only; never describe it as universal semantic equivalence or proven cross-architecture assurance.
